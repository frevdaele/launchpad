# Icons

- App logos (`*.svg`): [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons) and [simple-icons](https://simpleicons.org).
- Website favicons (`*.png`, max. 128 px): from the site itself, or via `https://www.google.com/s2/favicons?domain=<site>&sz=128`.
- `generic.svg` is shown for a link without `data-icon`, or when an icon fails to load.

To add a link: put the icon in this folder and give the link `data-icon="name.svg"`.
